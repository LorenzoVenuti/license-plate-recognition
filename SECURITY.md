# Politica di sicurezza

## Versioni supportate

| Versione | Supportata |
|----------|-----------|
| ultima release | sì |
| versioni precedenti | no |

## Segnalare una vulnerabilità

**Non aprire una issue pubblica.** Usa la funzione *Report a vulnerability* nella scheda
**Security** del repository (private vulnerability reporting), oppure scrivi in privato al
manutentore.

Nella segnalazione, se possibile: descrizione del problema, passi per riprodurlo, impatto
stimato e versione interessata.

La segnalazione riceve un riscontro appena possibile; la divulgazione pubblica avviene dopo che
è disponibile una correzione.
