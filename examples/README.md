# Examples

Put your own test media here — the code expects:

- `examples/car.jpg` — a still image with a visible plate
- `examples/input.mp4` — a video clip to annotate (the run writes `examples/output.mp4`)

No sample media is shipped in this repository: the models were trained and
tested on real vehicle images, and real, readable plates are personal data of
third parties. Use images you have the right to use — for instance from a public
dataset such as the Roboflow / Kaggle license-plate sets referenced in the
README, or photos where the plate is not identifiable.
